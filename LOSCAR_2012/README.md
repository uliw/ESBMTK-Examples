# LOSCAR Model 

This directory contains the ESBMTK implementation of [Zeebe (2012)'s LOSCAR model](https://doi.org/10.5194/gmd-5-149-2012).

- `LOSCAR_modern_example.py` is the modern (pre-industrial) model definition.
- `LOSCAR_glacial_example.py` is the configuration for glacial experiments.
- `LOSCAR_sheets.xlsx` contains worksheets describing model configuration information used to initialize the model.
